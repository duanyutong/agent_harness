# Rust Coding Standards

Apply the following sources alongside the general review principles. Repository-specific guidance takes precedence where it conflicts with these standards.

- Follow the [Rust Style Guide](https://doc.rust-lang.org/style-guide/), using `rustfmt` for formatting.
- Apply the relevant [Rust API Guidelines](https://rust-lang.github.io/api-guidelines/) when designing and reviewing Rust APIs.
- Rust code must be linted with [Clippy](https://doc.rust-lang.org/clippy/usage.html), using the repository's lint configuration.
