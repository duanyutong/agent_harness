# Coding Standards

Apply the shared standards to the requested coding task. Repository-specific guidance takes precedence where it conflicts with these standards.

Resolve the following paths relative to this skill's directory:

- Always load the [general coding principles](./standards/principles.md).
- Load only the language-specific standards relevant to the task:

  - [Rust](./standards/rust.md)

If no guideline exists for a relevant language, apply established modern practices and standards for that language.
